# 元记忆原子定义

## 背景

SelfMind聚焦智能体记忆，走独立产品路线，用Nous团队验证。理论先行：先定义记忆的基本数据结构，再定义机制理论，最后实现和迭代系统。

本文档记录2026-05-25坦哥与苏哥的 foundational discussion，确定元记忆的原子形态。

## 核心原则

### 原则一：元记忆是信息的一种

元记忆（meta-memory）是智能体记忆的原子形态。它可以是：
- 事实（fact）
- 事件（event）
- 总结（summary）
- 观察（observation）

元记忆被唤起，强度增加。不被唤起，强度衰减。

### 原则二：本质与状态分离

- 存储态：静态。元记忆的本质（内容、类型、来源）不变。
- 运行态：动态。元记忆的状态随时间演进。
- 增强或衰减不改变本质，只改变状态。

### 原则三：记忆与Agent解耦

Agent的理解能力变化不是记忆的变化。记忆就是记忆，理解是Agent的事。两条原则：

- 置信度是Agent对记忆的评价维度，不是记忆本身的属性
- 记忆的语义理解变化属于Agent能力范畴，不存储在记忆原子中

### 原则四：关系是记忆之间的

元记忆之间的关系有独立的定义和属性。关系不是元记忆原子的内部字段，而是原子之间的一层独立结构。整个体系类似知识图谱，但有一个关键区别：

**普通知识图谱存储事实，事实不会衰减。SelfMind的记忆图谱存储记忆，记忆会衰减。**

## 元记忆原子形态

### 本质层（不变）

| 属性 | 说明 | 取值 |
|------|------|------|
| id | 唯一标识 | UUID |
| content | 记忆内容 | 事实/事件/总结/观察的具体文本 |
| type | 内容类型 | fact / event / summary / observation |
| source | 记忆来源 | observation（agent观察） / inference（agent推理） / input（外部输入） |

### 状态层（随时间变）

| 属性 | 说明 | 性质 |
|------|------|------|
| strength | 综合强度 | 核心状态，唯一指标。类似人类的"我还记不记得xxx"的整体感受 |
| created_at | 创建时间 | 衰减公式的锚点 |
| last_recalled_at | 最近唤起时间 | 影响衰减速率计算 |

### 计算层（不存储，实时算）

strength的值由多个因子共同决定，但这些因子不作为元记忆的独立字段存储，它们是strength的更新规则：

| 因子 | 说明 | 机制理论待定义 |
|------|------|----------------|
| decay_factor | 时间衰减 | 距离上次唤起越久，强度自然下降 |
| recall_factor | 唤起强化 | 每次被recall，强度增加 |
| connection_factor | 网络效应 | 关系边越多，越稳固 |
| conflict_factor | 竞争削弱 | 被矛盾记忆削弱 |

这些因子的具体公式、权重、交互方式，属于**机制理论**的范围，不在原子定义中规定。

## 与现有理论论文的关系

现有论文《SelfMind记忆引擎理论基础：能量景观模型》将记忆定义为四元组 m = (s, c, l, t)，即语义向量、置信度、认知层级、时间戳。

本次讨论对该定义提出了根本性修正：

1. **置信度c不应属于记忆原子**——Agent的评价维度，不是记忆属性（原则三）
2. **认知层级l不应属于记忆原子**——层级是分类/组织维度，不是原子本质属性
3. **核心状态应该是strength**——综合指标而非单维度confidence
4. **语义向量s属于计算层**——不是记忆原子的存储属性，需要时实时生成

论文需要修订，将四元组定义更新为本次讨论确定的原子形态。修订后的论文应将(s, c, l)从原子存储属性移到机制理论的计算模型中。
